🎮 Mission Briefing: How It Works

  1. Virtual Identity: Create an account or sign in to save your personal statistics, persistent session, and leaderboard rankings.
  2. Interoperability: Our Node.js backend communicates securely with the external Banana API (Documentation) to fetch puzzles without revealing answers.
  3. Event-Driven Battle: Every puzzle solved and attack launched dispatches internal game events, dynamically syncing the cooperative boss health via REST polling.
  4. Cooperative Victory: All players attack the same health pool. When the boss falls, everyone celebrates and a new raid can begin!

CIS046-3 Enterprise Themes & Architecture

Documentation and technical evidence demonstrating the four required themes for assessment review.

University of Bedfordshire Assignment Alignment

A. Version Control

Git repository with organized modular structure, clear commits, and feature branch workflow (develop / main). Encapsulation across routes, controllers, models, and services.

B. Event-Driven Programming

Client-side DOM event listeners, REST polling timers, and server-side Node.js EventEmitter publishing user, puzzle, and boss raid lifecycle events.

C. Interoperability

Official Banana API integration (doc.php). Server-side HTTP fetch, AbortController timeouts, procedural fallbacks, and server-validated solutions that never expose answers to the browser.

D. Virtual Identity

User registration, email/username validation, bcryptjs password hashing, persistent SQLite session store, secure cookies, and protected Express routes.

Enterprise Software Stack Overview

  • Frontend: Semantic HTML5, Modular CSS3 (Custom Properties, Keyframes, Flexbox/Grid), Vanilla ES6 JavaScript (Zero frontend frameworks).
  • Backend Server: Node.js, Express.js REST API with controller-service architecture.
  • Database: Native SQLite (node:sqlite) with Write-Ahead Logging (WAL) and foreign key enforcement.
  • Security: Parameterised SQL queries, bcrypt hashing, HttpOnly session cookies, server-side answer evaluation.
